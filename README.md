# Executive Productivity Agent

An AI-assisted executive productivity agent prototype designed for **Arjun Malhotra, VP Sales**. The system organizes meeting information, email commitments, calendar events, and personal reminders into an executive-focused dashboard.

- Live Streamlit Prototype: https://executive-appuctivity-agent-amskf9i5ydytfhjxnv3jot.streamlit.app/
- GitHub Repository: https://github.com/Abhiydv110/Executive-Productivity-Agent
## Project Overview

Executives receive information from multiple sources such as meetings, emails, calendars, and personal reminders. Important commitments can be missed when this information is distributed across different sources.

The **Executive Productivity Agent** brings the provided information together and helps identify:

* High-priority tasks
* Open commitments
* Upcoming meetings
* Unassigned responsibilities
* Important deadlines
* Source evidence behind task information
* Day-wise executive activities
* Answers to common executive productivity questions

The prototype is designed using only the source material provided in the assignment.

## Key Features

### 1. Executive Overview

Provides a quick overview of the executive, role, and assignment week.

### 2. Priority Dashboard

Displays tracked tasks with:

* Task name
* Owner
* Deadline
* Status
* Priority
* Category

The dashboard highlights critical and high-priority items.

### 3. Open Commitments

Tracks commitments assigned to Arjun and identifies items that remain open.

### 4. Calendar Monitor

Displays Arjun's scheduled meetings and blocked periods during the assignment week.

### 5. Source Evidence

The user can select a task and view the source information associated with that task.

This helps make the agent's output traceable to the provided assignment data.

### 6. Ask the Executive Agent

The prototype provides an interactive question-and-answer interface.

Example questions include:

* What needs my attention right now?
* What are my open commitments?
* What is the status of the vendor list?
* What is the status of the Mumbai office lease renewal?
* When is the Meridian Logistics call?
* What is the campaign deck status?
* What is the expense variance report status?

### 7. Day-wise Executive View

The user can select a day from:

* Monday — 21 Sep 2026
* Tuesday — 22 Sep 2026
* Wednesday — 23 Sep 2026
* Thursday — 24 Sep
